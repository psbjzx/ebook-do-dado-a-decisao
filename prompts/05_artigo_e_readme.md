# Prompt 05 - Artigo e documentação do repositório

Escreva um artigo em português brasileiro apresentando o projeto
“Do dado à decisão”. Explique o problema educacional, a escolha do tema,
o fluxo de prompts, a revisão dos números, a participação da IA e as
ferramentas efetivamente usadas. Use um tom claro de relato de projeto,
sem alegar experiência ou resultados que não foram produzidos.

O artigo deve ter título, introdução, desenvolvimento e encerramento,
estar pronto para revisão e publicação na comunidade DIO, e incluir
referência ao repositório de Felipe Aguiar fornecido no desafio.

Crie também um README com link para o PDF, link funcional para o artigo
incluído no próprio repositório, prompts, ferramentas, estrutura dos
arquivos e instruções de reprodução. Não invente uma URL de artigo
publicado ou um endereço de repositório pertencente ao autor.

Inclua um guia para publicar o artigo, adicionar sua URL pública ao README
e entregar o link real do repositório à DIO.
