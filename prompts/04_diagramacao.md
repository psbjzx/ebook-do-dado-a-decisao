# Prompt 04 - Briefing de diagramação

Diagrame um e-book em PDF com capa, sumário, capítulos curtos, exemplos,
tabelas, fórmulas, um gráfico comparativo e referências com links.

Use formato vertical de aproximadamente 160 × 230 mm. A identidade visual
deve combinar azul-marinho, verde, tons claros e tipografia legível.
Inclua o título “Do dado à decisão”, o subtítulo, o nome “Paulo Bernardo”
e a identificação de projeto educacional desenvolvido com apoio de IA.

Desenhe a capa com elementos vetoriais originais e gere o gráfico a partir
dos valores reais da carteira sintética do projeto. Não use imagem gerada
por IA para representar dados numéricos.

Mantenha uma coluna, margens consistentes, numeração, contraste adequado,
tabelas sem cortes e código com fonte monoespaçada. Renderize todas as
páginas e revise o resultado visualmente antes de disponibilizar o PDF.

## Implementação utilizada

A diagramação usa ReportLab, a capa é vetorial e o gráfico usa Matplotlib.
Este arquivo registra o briefing aplicado ao código de produção; não foi
enviado a Midjourney, Canva ou PowerPoint.
