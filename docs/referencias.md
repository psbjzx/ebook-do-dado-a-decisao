# Referências e créditos

Consultadas em 7 de outubro de 2026.

## Origem do desafio

- [Felipe Aguiar: prompts-recipe-to-create-a-ebook](https://github.com/felipeAguiarCode/prompts-recipe-to-create-a-ebook). Referência do desafio para o uso de prompts na produção de um e-book.

## Conceitos e código

- [scikit-learn: Tweedie regression on insurance claims](https://scikit-learn.org/stable/auto_examples/linear_model/plot_tweedie_regression_insurance_claims.html). Apoio às definições de frequência, severidade e custo por exposição. Este projeto utiliza um caso sintético próprio e uma análise descritiva.
- [scikit-learn: Common pitfalls and recommended practices](https://scikit-learn.org/stable/common_pitfalls.html). Apoio à explicação de separação de dados e vazamento de informação.
- [Python: json](https://docs.python.org/3/library/json.html). Leitura e gravação de dados estruturados.
- [Python: decimal](https://docs.python.org/3/library/decimal.html). Aritmética decimal usada na análise.
